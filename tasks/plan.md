# Implementation Plan: Feature 7 — Automatic translation

Spec: [07-auto-translation.md](../specs/07-auto-translation.md) · Task list: [todo.md](todo.md) · Branch: `feature/auto-translation`

## Overview

French becomes the writing language; English is generated by DeepL (EN-GB), on demand in the editor or automatically for empty fields on save. Markdown survives through an HTML round trip. Saving never fails because of DeepL.

## Architecture Decisions

- **One translation service in infra** (`infra/translation.py`): converts Markdown ↔ HTML and calls DeepL through an injected `httpx.AsyncClient`, so tests use `httpx.MockTransport` (no new test dependency, no network).
- **All failures become `TranslationUnavailable`** (no key, bad key, quota, timeout, network); callers decide: the translate endpoint answers 503, the save endpoint keeps French and flags `translation_failed`.
- **Source language in the domain** (`SOURCE_LANG = "fr"`): `localize()` falls back to it, so the public site shows French when English is empty.
- **Auto-fill only empty English fields**: the save endpoint never overwrites English text the admin wrote.
- **Short timeout (10 s)** on DeepL calls so a slow DeepL does not hang the editor.

## Creating the DeepL key (for Checkpoint A)

1. Go to <https://www.deepl.com/pro-api> and choose **DeepL API Free** (not "DeepL Pro" for individuals).
2. Create the account; DeepL asks for a card to verify identity — the Free plan is not charged.
3. In your account: **API Keys** → copy the key (it ends with `:fx` for Free keys).
4. Add to `backend/.env` (never committed): `DEEPL_API_KEY=<your key>`
5. Restart the backend.

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| DeepL alters Markdown | Med | HTML round trip with `tag_handling=html`; round-trip and fake-translation tests |
| Key leaked | High | Read from environment only; never logged or returned; `.env` git-ignored; checklist entry for production |
| DeepL down or quota reached | Med | Save still succeeds (French), clear warning; 503 on the button |
| Free quota (500k chars/month) exhausted by repeated clicks | Low | Admin-only endpoint, 10 items × 5,000 chars max per call; usage far below the quota |
| French required breaks existing content | Low | Current row already has French; placeholder migration unchanged |
